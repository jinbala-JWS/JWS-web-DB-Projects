# 오늘의 미니 프로젝트 3종 🎯🌀🐍

빌드 과정이나 설치가 필요 없는, 각 폴더의 `index.html`을 더블클릭(또는 브라우저로 열기)하면 바로 실행되는 단일 파일 웹앱 3개입니다.

| 폴더 | 종류 | 내용 |
|---|---|---|
| [productivity-pomodoro](productivity-pomodoro/index.html) | 생산성 도구 | 뽀모도로 타이머(원형 프로그레스, 집중/휴식 자동 전환) + 할일 목록. `localStorage`에 저장됩니다. |
| [creative-spirograph](creative-spirograph/index.html) | 창의적 장난감 | 스피로그래프 스튜디오. R/r/d 값과 속도, 색상을 조절해 패턴을 그리고, 마우스로 직접 드로잉하거나 PNG로 저장할 수 있습니다. |
| [game-neon-snake](game-neon-snake/index.html) | 게임 | 네온 스네이크. 방향키/WASD/스와이프 조작, 속도 단계 증가, 최고 점수 저장(`localStorage`). |

## 실행 방법
각 폴더의 `index.html` 파일을 더블클릭해서 기본 브라우저로 열면 됩니다. 서버나 설치가 필요 없습니다.

## 다음에 추가하면 좋을 것들 (아이디어)

- **Spirograph Studio**: 여러 겹 레이어 합성, GIF 내보내기
- **Neon Snake**: 장애물 모드, 2인 대전 모드
