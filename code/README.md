# CPI 다음달 예측 프로그램 - 코드

`../CPI_예측_프로그램_설계도.md` 설계를 실제로 구현한 버전.

## 실행 순서

```bash
pip install -r requirements.txt

python data_pipeline.py   # 원본 파일 파싱 -> processed/ 에 정제 데이터 저장
python run_forecast.py    # Tier별 예측 + 라스파이레스 재구성 -> 다음달 총지수 예측
```

`run_forecast.py`는 실행에 수 분(Tier A 363개 품목의 Holt-Winters/백테스트 때문) 걸립니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `data_pipeline.py` | CPI 원본(.xls, SpreadsheetML)·가중치·Tier분류·외부데이터를 정제해 `processed/`에 저장 |
| `models.py` | Tier A/B/C/D 예측 함수 |
| `run_forecast.py` | 메인 실행: 458개 품목 예측 → 가중합 → 대분류/총지수 산출 |
| `manual_overrides.json` | Tier C(공공요금)·D(전기/가스/난방) 수동 반영용. `{"품목코드": {"mom_pct": 3.5, "note": "..."}}` 형식 |
| `processed/` | 파이프라인/예측 결과물 (재실행하면 매번 갱신됨) |

## 결과물 (`processed/`)

- `forecast_result_items.csv` — 458개 품목별 예측치·방법·전월비%
- `forecast_result_categories.csv` — 대분류 12개 예측치
- `forecast_summary.json` — 총지수 예측치, 검증(재구성 오차) 요약

## Tier별 방법론 요약

- **A (일반 시장가격형, 363개)**: 계절나이브/드리프트/Holt-Winters 중 최근 6개월 백테스트 최우수 모델을 자동 선택. 변동성 큰 품목은 소속 대분류의 최근 추세로 축소(shrinkage).
- **B (계절형, 55개)**: 최근 5개년의 "전월→해당월" 변동률 중앙값을 사용(STL 추세외삽은 검증 중 극단치 문제로 폐기). 고정계절 11개 품목이 미출하월에 해당하면 통계청 공식 "대체" 방식(같은 신선분류군 비계절품목 평균 모멘텀)을 그대로 적용.
- **C (정기개정형, 31개)**: 기본값은 보합(0%). `manual_overrides.json`으로 알게 된 요금 변경을 반영.
- **D (원자재연동형, 9개)**: 오피넷 실측 있는 6개 품목(휘발유·경유·등유·자동차용LPG 등)은 외부지표 회귀. 전기료·도시가스·지역난방비는 Tier C와 동일(보합+수동반영). 취사용LPG·부탄가스는 외부데이터 없어 Tier A 방식 폴백.

## Tier A 농축산물 외부가격 (`collect_market_prices.py`)

Tier A 품목 중 곡물·축산물·유제품은 KAMIS(농산물유통정보)·축산유통정보(다봄)의 "전국 평균 소매가"로
보완 가능한지 검증 후 수집기를 만들었다.

**검증 결과** (2026-08-10 기준, CPI 실제 지수와 비교):
- 쌀(KAMIS) vs CPI 쌀지수: 레벨상관 0.98, 전월비상관 0.86
- 돼지고기(축산유통정보) vs CPI 돼지고기지수: 레벨상관 0.94, 전월비상관 0.89

**실행**: `python collect_market_prices.py` → `processed/market_prices_daily.csv`에 오늘 날짜로 1행 추가(재실행하면 같은 날짜는 덮어씀). 아직 스케줄 자동화는 안 돼있음 — 매일 수동 실행.

**현재 상태**:
| 품목군 | 상태 |
|---|---|
| 축산물 5개(국산쇠고기·돼지고기·닭고기·달걀·우유) | ✅ 완전 자동화 (축산유통정보, requests만으로 동작) |
| 곡물 7개(쌀·찹쌀·보리쌀·혼식곡·현미·콩·땅콩) | ❌ KAMIS가 requests로는 500 에러 — 원인 미해결. 당장은 브라우저로 수동 조회 필요 |

## 알려진 한계 (다음 개선 대상)

1. **검증 오차 존재**: 지난달(가장 최근 실측월)을 같은 가중합 방식으로 재구성하면 공식 총지수와 약 ±0.5~0.6% 오차가 남음 — 가중치를 2022년 단일 시점만 쓰고 있어서(공식은 매년 미세 조정 + 위계별 라스파이레스), 정확히 일치하지 않음. `forecast_summary.json`의 `reconstruction_error_pct`로 매번 확인 가능.
2. **가중치 히스토리 파싱 미완성**: `weight_history.csv`(8개 시점별 가중치)가 아직 정확히 파싱되지 않음 — 현재는 Tier 분류표의 2022년 가중치 하나만 사용해서 다음달 예측은 문제없지만, 과거 여러 해에 걸친 백테스트를 하려면 이 부분을 고쳐야 함.
3. **백테스트 미구현**: 지금은 "다음달 1회 예측"만 함. 여러 달에 걸친 워크포워드 백테스트(예측 정확도를 과거 데이터로 검증)는 아직 없음.
4. **Tier C/D 수동 반영 데이터 없음**: 전기료·도시가스·지역난방비 요금 개정 이력이 아직 `manual_overrides.json`에 들어있지 않아 항상 보합으로 처리됨.
