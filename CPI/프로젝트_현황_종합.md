## 전체 파이프라인 관점에서 남은 일 (모든 Tier 공통)

데이터 수집은 Tier별로 진도가 다르지만, **예측 모델 구현은 4개 Tier 전부 아직 시작 전**이다.
다음 단계는 규모 순으로:

1. Tier A/B: 자체 히스토리만으로 동작하는 baseline 모델(SARIMA/ETS/STL) 구현 — 데이터는 이미
   있으므로 가장 먼저 코드화 가능, 전체 가중치의 79.5%를 차지해 파급력이 가장 큼.
2. Tier C/D: API 키 도착 대기 + 미해결 10개 항목(특히 휴대전화료) 조사 계속.
3. 모든 Tier의 개별 예측치를 공식 가중치([CPI_Tier_분류.csv](./CPI_Tier_분류.csv))로
   라스파이레스 재구성해 다음달 총지수 산출 — 아직 로직 미구현.
4. 백테스트: 과거 특정월을 "다음달"로 가정하고 예측 vs 실제 공식지수 비교, 오차 검증.
