# CPI(소비자물가지수) 다음달 예측 프로그램 — 설계도

> 통계청 「소비자물가조사」(승인번호 101007) 공식 산정방식을 기반으로, 다음달 전국 소비자물가 총지수를 예측하는 프로그램의 설계 문서.
> 작성 기준일: 2026-08-09

---

## 1. 목적

`CPI` 폴더에 수집한 통계청 원본 데이터와 공식 산정방식(라스파이레스 가중산술평균)을 그대로 재현하는 **Bottom-up 구조**로 다음달 총지수를 예측한다.

```
[품목/분류별 개별 예측] → [공식 가중치로 라스파이레스 재구성] → [다음달 총지수 예측치]
```

## 2. 공식 산정방식 요약 (KOSIS 통계설명자료 기준)

| 항목 | 내용 |
|---|---|
| 지수산식 | 가중산술평균법 — 라스파이레스 산식(Laspeyres' Formula) |
| 기준연도 | 지수 2020년=100 / 가중치 2022년 기준 |
| 대상품목 | 458개 대표품목(1,057개 규격) |
| 조사 | 40개 도시 155개 권역, 약 26,000개 점포+11,000 가구, 매월 초·중·하순(품목군별 상이) |
| 공표 | 매월 익월 초 (→ 항상 1개월의 발표 시차 존재) |
| 분류체계 | 지출목적별(12대/39중/71소) + 품목성질별(상품310/서비스148) |
| 부지수 | 생활물가지수, 신선식품지수, 농산물및석유류제외지수, 식료품및에너지제외지수(OECD 근원), 자가주거비포함지수 |
| 계절조정 | 미실시 (모델에서 직접 계절성 처리 필요) |
| 가중치 개편주기 | 2~3년 (연도 끝자리 0,2,5,7년), 조사도시·품목·기준년은 5년 주기 |

## 4. 품목 분류 체계 (4-Tier)

특수분류 파일의 공식 플래그를 그대로 근거로 사용해 자동 분류했다 (수작업 태깅 없음).

| Tier | 개수 | 판정 기준 | 예측 방법론 |
|---|---:|---|---|
| **A. 일반 시장가격형** | 363개 | 나머지 전체 (기본값) | 소분류(71)/중분류(39) 단위로 SARIMA/ETS 등을 자체 히스토리(26년)로 백테스트해 자동 선택. 노이즈 큰 소분류는 상위분류 추세로 축소(shrinkage) |
| **B. 계절형** | 56개 | 공식 "신선식품지수" 플래그 — 신선어개 11·신선채소 27·신선과실 18 | 고정계절 11개 품목(아래 표)은 통계청 공식 "대체" 로직 그대로 적용. 나머지는 STL 분해(추세+계절+잔차)로 자체 계절성 학습 |
| **C. 정기개정형(계단식)** | 31개 | 공식 "품목성질=공공서비스" 플래그 + 담배(수동 편입) — 상하수도료·버스/택시/철도/항공료·통신료·진료비·등록금류·행정수수료 등 | 시계열모델 대신 **직전 개정 후 경과월 추적 + 뉴스/공지 기반 수동 반영** |
| **D. 원자재연동형** | 9개 | 공식 "에너지" 특수분류 플래그 — 전기료·도시가스·취사용LPG·등유·지역난방비·부탄가스·휘발유·경유·자동차용LPG | 아래 6장 참조 |

## 5. 외부데이터 없이도 항상 동작하는 기본 원칙

> **원칙: 각 품목/분류 자체의 과거 시계열(추세+계절성) + 통계청 위계구조만으로 항상 동작하는 것이 기본값. 외부데이터는 확보되는 대로 얹는 보조 신호.**

- Tier A: 외부 회귀변수 없이 자체 히스토리로 SARIMA/ETS 적합 → 추후 PPI·환율 등이 확보되면 잔차에 회귀항으로 추가
- Tier B: 처음부터 자체 계절성 학습이 핵심이라 외부데이터 비의존 설계
- Tier C: 애초에 시장가격이 아니라 규제요금이므로 뉴스/공지 확인 기반
- Tier D: 외부데이터(오피넷 등)가 있으면 우선 사용, 없는 하위품목은 Tier A식 자체모델로 폴백
