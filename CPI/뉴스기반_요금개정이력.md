# Tier C/D 요금 개정 이력 — 뉴스/공지 기반 수집 (2026-08-19)

> API 키 없이 웹서치로 수집한 규제요금 개정 연혁. 각 항목 말미에 통계청 공식 CPI
> 세부지수([official_tierCD_monthly.csv](./scripts/official_tierCD_monthly.csv))에서 실제로
> 관측되는 전월대비 급등 시점과 대조한 검증 결과를 붙였다 — **모든 항목에서 뉴스 발표 시점과
> CPI 지수 급등월이 사실상 일치**함을 확인했으므로, Tier C 설계 원칙("직전 개정 후 경과월
> 추적 + 뉴스 기반 수동 반영")이 실제로 유효하다는 근거가 된다.

## 종합 평가

뉴스/공지 기반 마일스톤 방식이 **6개 항목 모두에서 CPI 실측 급등 시점과 높은 정합성**을 보였다.
다만 지자체별 편차가 큰 품목(시내버스료·상하수도료 등)은 전국 대표 시점 포착이 부정확해서,
행정안전부 지방공공요금 현황(API 필요, [설계도 6-2절](./CPI_예측_프로그램_설계도.md) 참조)으로
보완이 필요하다는 게 확인됐다.
