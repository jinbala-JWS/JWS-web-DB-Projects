# 2026년 10월 CPI 예측 — 20일 시점 갱신 (2026-10-21)

[2026년10월_CPI_예측_상반월.md](./2026년10월_CPI_예측_상반월.md)(10/12, 오피넷 MTD 10일)의
후속 갱신. 오피넷 MTD를 **10일→20일(영업일 기준 월 전체의 약 65%)**로 확장하고, 이번엔
**R-ONE(한국부동산원) 전세·월세 지수를 직접 API로 확보해 교차검증**까지 반영했다. 10월
공식 발표(KOSIS)는 11월 초 예정.

## 0. 이번 회차에 새로 반영한 것

1. **오피넷 MTD 10→20일**: [daily_price_collector.py](./일별가격추적/daily_price_collector.py)가
   돌아가는 사용자 PC가 10/13 이후 수집을 멈춰(daily_price_log.csv 공백) 이번엔 오피넷
   원본 API(`dopospdrg/dopOsPdrgSelect.do`, `dopvsavsel/dopVsAvselSelect.do`)를 이 세션에서
   직접 호출해 10/14~10/21 수집분(기준일 10/13~10/20)을 `daily_price_log.csv`에 백필한 뒤
   [append_opinet_mtd.py](./scripts/append_opinet_mtd.py) 재실행 — 휘발유 1856.93 / 경유
   1842.93 / 등유 1572.55 / 자동차용LPG 1143.18원(20일 평균).
2. **R-ONE "주택종합" 전세·월세 지수 직접 확보(최초)**: 지금까지는 R-ONE 차트 페이지가
   JS로 비동기 호출하는 내부 API 파라미터를 몰라 매번 수동 캡처에 의존했는데, 이번에
   Playwright(사전 설치된 Chromium)로 `chgRate/tradeChgStatsPage.do` 접속 시 발생하는 실제
   요청을 스니핑해 **`searchRegionChartData.do`(POST, `itmId=1000010`=전국·`hdnChgType=01`=
   전월대비%·`dtacycleCd=MM`, 응답의 `BLD_GB`: 01=매매/02=전세/03=월세)** 엔드포인트와
   파라미터를 코드로 재현 가능하게 확인했다 — 브라우저 없이 매달 재호출 가능.
   2026-08(전세 0.35%/월세 0.35%), 2026-09(전세 0.34%/월세 0.39%) 두 달치를 신규 확보해
   [rone_vs_cpi_monthly.csv](./scripts/rone_vs_cpi_monthly.csv)에 추가하고 1개월 시차
   회귀모델을 재적합했다(R-ONE_CPI_전월세_회귀모델.md 갱신 필요 — 아래 §3).

## 3. R-ONE 전세·월세 교차검증 (이번 회차 신규)

1개월 시차 회귀모델(CPI(t) ~ R-ONE(t-1))을 8·9월 두 포인트 추가해 재적합(n=13):

| | 기울기 | 절편 | R² | p-value |
|---|---:|---:|---:|---:|
| 전세 | 0.4261 | -0.0090 | 0.6154 | 0.0015 |
| 월세 | 0.3151 | +0.0274 | 0.5300 | 0.0048 |

기존(n=11, [R-ONE_CPI_전월세_회귀모델.md](./R-ONE_CPI_전월세_회귀모델.md))보다 R²가 더
올라갔다(전세 0.525→0.615, 월세 0.407→0.530) — 표본이 쌓일수록 적합도가 개선되는 추세.

## 5. 한계

- 오피넷 MTD는 여전히 20/31일(약 65%)이고, 특히 자동차용LPG는 10월 들어 추가 고시가
  없었던 것으로 보여(10/13~10/20 거의 변동 없음) 월말까지 이 흐름이 유지될지 재확인 필요.
- 사용자 PC의 `daily_price_collector.py` 자동수집이 10/13 이후 끊겼다(Windows 작업
  스케줄러 미실행 추정) — 이번엔 이 세션에서 오피넷 원본을 직접 재조회해 공백을 메웠지만,
  원래 자동수집 경로가 복구됐는지 확인 권장.
- 09월 KOSIS 세부품목(458개) 실측은 이미 반영됐으나, 10월 바텀업 편향보정은 여전히
  2026-02~07 트레일링 백테스트 기준(8·9월 신규 포인트 미반영) — 다음 갱신 때 확장 검토.
