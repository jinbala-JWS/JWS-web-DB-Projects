# CPI 관련 데이터 관리대장 (2026-08-25 작성)

지금까지 이 프로젝트에서 확보한 **외부 원본 데이터**를 어느 Tier(A/B/C/D)를 지원하는지
기준으로 구분하고, 각각 **업데이트 주기·갱신 방법·최근 확인일**을 정리한다. 새 세션에서
데이터를 갱신할 때 이 표만 보고 "무엇을 언제 다시 받아야 하는지" 판단할 수 있게 하는 것이
목적이다.

> 파일 위치는 옮기지 않았다(자동 실행 중인 일별 수집 스케줄러 `CPI_DailyPriceCollector`가
> 참조하는 경로를 건드리면 자동화가 깨질 수 있어서) — 대신 이 문서가 Tier별 색인 역할을 한다.
> 실제 파일은 모두 `CPI/scripts/` 또는 `CPI/일별가격추적/` 안에 그대로 있다.

**업데이트 주기 범례**: 🔴일간 · 🟠주간 · 🟡월간 · ⚪비정기(고시·개정 시) · ⚫최초 1회(정적)

## Tier B (계절형) — 외부 원본데이터 없음 (공백)

과일·채소 등 계절 품목은 현재 KOSIS 자체 히스토리(계절ETS)만으로 예측 중이며, 이를
검증할 별도 외부 원본데이터는 아직 확보하지 못했다. 후보로 파악해둔 것: 농산물유통정보
(KAMIS, [www.kamis.or.kr](https://www.kamis.or.kr)) 도매가 — 추후 착수 시 여기에 행을 추가할 것.

## Tier C (정기개정형) — 텍스트 기록만 존재, CSV 미보유

전기료·상하수도·대중교통·등록금 등 40개 품목의 요금개정 이력은
[데이터수집_현황.md](./데이터수집_현황.md)에 **표 형태 텍스트**로만 기록되어 있고, 아직
구조화된(CSV) 시계열 파일은 없다. 성격상 "매일/매월 갱신"이 아니라 **고시가 날 때만
갱신**되는 항목이라 아래 일정으로 재확인 권장:

| 갱신 트리거 | 대상 품목(예시) |
|---|---|
| ⚪매년 4월경(등록금 고시) | 전문대·국공립대·사립대·대학원 납입금 5종 |
| ⚪비정기(공공요금 고시, 보통 연 1~2회) | 전기료·도시가스·지역난방비·상하수도료 |
| ⚪비정기(지자체/사업자 고시) | 시내버스료·택시료·도시철도료 |

## 다음 정기 점검 체크리스트 (예측 실행 전 매번 확인)

1. `일별가격추적/run_log.txt` 확인 — 최근 며칠 자동수집이 끊기지 않았는지
2. Tier D 오피넷 이력(raw_opinet_*.tsv) — 예측 대상월이 바뀌면 재조회
3. R-ONE 주간(목요일)·월간(15일) 발표 여부 확인 후 rone_*.tsv 갱신
4. KOSIS 공식 CPI 익월 초 발표 여부 확인 — 새 실측월이 생기면 cpi_official_monthly_wide.csv 재생성 → 전체 백테스트/예측 파이프라인 재실행
5. ECOS PPI(익월 하순)·MOLIT(익월 지연) — 발표 주기가 CPI보다 늦으므로 항상 "직전월까지"만 확정치로 취급
