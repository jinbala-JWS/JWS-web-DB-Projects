# 9월 CPI 전세·월세 예측 — R-ONE 데이터 반영 (2026-10-13)

## 배경

9월 예측(forecast_september_2026.py, 3차·최종)은 R-ONE 없이 전세·월세를 자체
히스토리 비계절ETS로만 예측했다(106.558 / 106.169). 사용자가 네트워크 접근을
허용해줘서 이번에 R-ONE 데이터를 직접 받아와 반영했다.

## 1. 데이터 — 이번엔 "주택종합" 지수를 직접 확보

8월 작업([R-ONE_CPI_전월세_회귀모델.md](./R-ONE_CPI_전월세_회귀모델.md),
[8월_전세상승률_예측_R-ONE주간기반.md](./8월_전세상승률_예측_R-ONE주간기반.md))에선
"주택종합" 수치를 차트 페이지(`chgRate/tradeChgStatsPage.do`)에서 변동률(%)만
읽어왔고, 월간 데이터는 8월분이 미발표라 주간(아파트만) 데이터로 추정했다.

이번엔 한국부동산원 통계DB(`통계조회`) 내부 API `sttsDataPreviewList.do`를
직접 호출해(세션 쿠키만 필요, 별도 인증키 불필요) **지수 레벨 원자료**를 확보했다 —
8월분이 이미 발표(9/15경)돼 있어 더는 주간 추정이 필요 없었다.

- `A_2024_00019` = (월) 전세가격지수_주택종합, 전국
- `A_2024_00022` = (월) 월세가격지수_주택종합, 전국
- 호출 파라미터는 easyStatPage(`A_2024_00019.do`)의 `firParam` 히든필드에서 확인:
  `viewLocOpt=B&wrttimeType=L&dtadvsVal=OD&dtacycleCd=MM&optDivVal=00&isRegionData=Y&searchType=S` 등
- 원본: [rone_housing_composite_jeonse_wolse.tsv](./scripts/rone_housing_composite_jeonse_wolse.tsv)

| 년월 | 전세가격지수 | 월세가격지수 |
|---|---:|---:|
| 2026-06(기준월) | 100.00 | 100.00 |
| 2026-07 | 100.38 | 100.48 |
| **2026-08** | **100.74** | **100.90** |

전월대비: 전세 **+0.3586%**, 월세 **+0.4181%** (2026-07→08).

**검증**: 이 API로 환산한 2025-11~2026-07 전월대비 값이 기존에 차트에서 수동으로
읽어온 값([R-ONE_CPI_전월세_회귀모델.md](./R-ONE_CPI_전월세_회귀모델.md) 1절)과
소수점 둘째 자리까지 일치 — 같은 API를 쓰지 않고도 교차검증됨.

## 2. 1개월 시차 회귀모델 재적합 (8월 포인트 추가)

기존 모델(11쌍)에 2026-08 R-ONE→CPI 쌍을 추가해 12쌍으로 재적합:

| | 기울기 | 절편 | R² | p-value | (기존, 11쌍) |
|---|---:|---:|---:|---:|---|
| 전세 | 0.4179 | -0.0077 | **0.5915** | 0.0035 | 0.356 / 0.003 / R²0.525 |
| 월세 | 0.3027 | 0.0295 | **0.4979** | 0.0103 | 0.230 / 0.044 / R²0.407 |

표본이 하나 늘면서 R²도 소폭 개선(전세 0.525→0.592, 월세 0.407→0.498).

## 3. 9월 CPI 전세·월세 예측

R-ONE(8월) 값을 재적합 모델에 대입:

| 품목 | R-ONE(8월) | CPI 9월 전월대비 예측 | CPI 9월 지수 예측(R-ONE) | 기존 ETS 예측 | 차이 |
|---|---:|---:|---:|---:|---:|
| 전세 | +0.3586% | +0.1421% | **106.531** | 106.558 | -0.027 |
| 월세 | +0.4181% | +0.1561% | **106.185** | 106.169 | +0.016 |

8월과 마찬가지로 **두 방법이 0.03%p 이내로 거의 일치** — 자체 ETS 예측이 R-ONE
독립 데이터로 다시 한번 교차검증됐다.

## 4. 바텀업 총지수 반영

[update_september_total_with_rone.py](./scripts/update_september_total_with_rone.py)로
458개 품목 바텀업 집계에서 전세·월세만 R-ONE 기반 값으로 교체:

```
교체 후 바텀업 총지수(R-ONE 반영): 120.3723

```

원본: [september2026_bottomup_items_roneupdate.csv](./scripts/september2026_bottomup_items_roneupdate.csv)

## 5. 공식(하이브리드) 총지수는 불변 — 왜?

9월 예측은 [2026년9월_CPI_예측.md](./2026년9월_CPI_예측.md)부터 **하이브리드
방식을 공식으로 채택**했는데, 전세·월세가 속한 "04 주택,수도,전기및연료"
카테고리는 하이브리드 판정에서 **탑다운(카테고리 자체 히스토리 ETS)이 채택**됐다.
탑다운은 458개 품목을 합산하는 게 아니라 "04" 카테고리 지수 자체의 시계열로
직접 예측하므로, 전세·월세 품목 값을 바꿔도 탑다운 결과(그리고 그걸 쓰는
하이브리드 공식 총지수 120.503)에는 전달되지 않는다.

즉 이번 R-ONE 반영은 **공식 예측치를 바꾸지는 않지만**, 바텀업 총지수가 거의
그대로였다는 점(-0.0008)과 전세·월세 개별 품목이 독립적인 외부 데이터로도
교차검증됐다는 점에서 **9월 예측 전체의 신뢰도를 한 번 더 뒷받침하는 근거**로
기록해둔다.

## 한계

- R-ONE 9월치는 아직 미발표(10/15경 예정) — 이번 반영은 "R-ONE(8월)→CPI(9월)"
  시차모델이라 R-ONE 9월 실측치 자체를 쓴 게 아니다.
- sttsDataPreviewList.do는 `wrttimeLastestVal`을 30까지 올려도 실제로는 최근
  10개월만 반환함을 확인 — 더 긴 히스토리가 필요하면 R-ONE Open API(인증키 필요)로
  전환해야 한다.
