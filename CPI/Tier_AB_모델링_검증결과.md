# Tier A/B 모델링 + 워크포워드 백테스트 결과 (2026-08-19, 재분류 반영 최신본)

> **2026-08-19 업데이트**: 최초 결과에서 Tier A로 분류돼 있던 승용차임차료·콘도이용료·
> 국내항공료 3개 품목이 계절성이 뚜렷해(MAPE 7~10%) Tier B로 재분류됐고, 계절ETS로
> 재모델링한 결과가 아래 최신 수치에 반영돼 있다. 개선 결과는 문서 하단 "재분류 효과" 참조.

## 방법론

- **대상**: Tier A(일반 시장가격형) 360개 + Tier B(계절형) 58개, 총 418개 품목 (가중치 합 794.9/1000)
  — 승용차임차료·콘도이용료·국내항공료는 최초 A로 분류됐다가 재분류를 거쳐 B로 이동(하단 참조)
- **모델**: `statsmodels.ExponentialSmoothing`
  - Tier A: 추세=완만감쇠(damped additive trend), 계절성 없음
  - Tier B: 추세=완만감쇠 + 계절성(월별, period=12). 고정계절 11개 품목(복숭아·포도·감·귤·오렌지·
    참외·수박·딸기·체리·열무·굴)은 2017-01 이후 데이터만 사용(이월→대체 방식 변경 반영)
  - 데이터 24개월 미만이거나 적합 실패 시 최근 12개월 평균변화율 기반 랜덤워크로 대체
- **검증 방식**: **워크포워드(rolling one-step-ahead)**. 2025년 12월까지의 실제 데이터로
  2026년 1월을 예측 → 실제 1월 데이터가 들어왔다고 가정하고 다시 적합해 2월을 예측 →
  … → 2026년 7월까지 반복(매 스텝 재적합, 미래 정보 누출 없음).
- **집계**: 각 Tier 내 가중치([CPI_Tier_분류.csv](./CPI_Tier_분류.csv))로 가중평균해 Tier
  단위 지수를 구성(공식 라스파이레스 가중치 그대로 사용, 단 개별품목이 이미 지수형태라 산술
  가중평균으로 근사).
- 코드: [forecast_tierAB.py](./scripts/forecast_tierAB.py), [evaluate_tierAB_forecast.py](./scripts/evaluate_tierAB_forecast.py)
- 원본 결과: [tierAB_forecast_vs_actual.csv](./scripts/tierAB_forecast_vs_actual.csv) (품목별 예측·실제 전체),
  [tierAB_aggregate_comparison.csv](./scripts/tierAB_aggregate_comparison.csv),
  [tierAB_item_accuracy.csv](./scripts/tierAB_item_accuracy.csv)

## 결과 2 — 품목별 정확도(MAPE)

- 418개 품목 전체 MAPE 평균 1.38%, 중앙값 0.52%
- **가중평균 MAPE(가중치 반영): 0.80%** — 가중치 큰 품목일수록 상대적으로 더 잘 맞았다는 뜻
- 방향적중률(전월대비 상승/하락 방향 일치) 평균 47.8% — 얼핏 낮아 보이지만, Tier A 품목의
  실제 월간 변화폭 중앙값이 0.28포인트에 불과해(거의 안 움직임) 방향 자체가 노이즈에 가까운
  경우가 많음. **레벨(수치) 오차가 작다는 게 더 중요한 지표**이며 그 기준으로는 양호.

### 가장 정확했던 품목 (MAPE 최저)
자동차검사료(0.00%), 지갑, 영화관람료, 금융수수료, 피자, 보일러, **월세(0.03%, 가중치 44.9)**,
**전세(0.03%, 가중치 54.2)** — CPI 최대 가중치 품목인 전월세가 매우 정확하게 예측됨.

### 가장 부정확했던 품목 (가중치 0.5 이상 중 MAPE 최고)
호박(16.3%)·파(12.4%)·상추(10.6%)·파프리카(9.4%)·배추(9.2%)·오이(8.7%)·참외(7.4%) — 전부
Tier B 신선채소/과실. 기상 등 단기 충격에 즉각 반응하는 특성상 26년 자체 히스토리만으로는
한계가 뚜렷함(설계상 예상된 결과).

## 재분류 효과 — 승용차임차료·콘도이용료·국내항공료 (A→B)

최초 결과에서 Tier A(비계절 모델)로 큰 오차를 보였던 3개 품목을 Tier B(계절ETS)로 재분류해
다시 적합한 결과:

| 품목 | 가중치 | MAPE (재분류 전, 비계절) | MAPE (재분류 후, 계절) | 개선 |
|---|---:|---:|---:|---|
| 국내항공료 | 1.0 | 7.01% | **5.64%** | ✅ 뚜렷한 개선 |
| 콘도이용료 | 0.8 | 9.65% | **5.52%** | ✅ 뚜렷한 개선 |
| 승용차임차료 | 3.2 | 10.45% | 10.17% | ⚠️ 소폭 개선에 그침 — 계절성 외 다른 요인(렌터카 성수기 가격정책 등) 추가조사 필요 |

Tier A+B 결합 가중집계 지수의 월별 오차는 재분류 전후로 거의 동일(±0.4%p 이내) — 이 3개
품목의 가중치가 작아(합 5.0/1000) 전체 총지수에는 영향이 미미하지만, **개별 품목 단위
예측 정확도는 확실히 개선**됐다.

## 다음 단계 제안

1. 승용차임차료는 계절 모델로도 MAPE 10%대 — 렌터카 성수기 요금정책 등 계절성 외 요인
   추가조사 필요
2. Tier B 신선채소류는 자체 히스토리 한계가 뚜렷 — 추후 기상데이터(강수량·기온) 등 외부
   회귀변수 도입 검토 (design doc 5장에서 이미 "확보되는 대로 얹는 보조신호"로 명시된 부분)
3. Tier C/D를 이 파이프라인에 결합해 전체 총지수 라스파이레스 재구성까지 확장
