# R-ONE "주택종합" 전세/월세 지수 — 유형별 가중치 분석 (2026-08-24)

## 질문
2026년 7월 전국주택가격동향조사(한국부동산원 R-ONE) 발표치:

| | 아파트 | 연립다세대 | 단독주택 | **종합** |
|---|---:|---:|---:|---:|
| 전세 전월대비 | +0.49% | +0.27% | +0.04% | **+0.38%** |
| 월세 전월대비 | +0.47% | +0.31% | +0.06% | **+0.38%** |

3개 유형이 어떤 비중으로 결합돼 "종합" 수치가 나왔는지 확인.

## 1) 공식 산정방식 확인 (원본 문서)

[공표보고서](https://www.reb.or.kr/r-one/portal/bbs/rpt/searchBulletinPage.do) →
"2026년 7월 전국주택가격동향조사" 보고서 PDF(32p, 통계개요) 직접 확인:

> **"주택재고량을 가중치로 한 제본스지수 산식(Jevons index formula)으로 계산"**
> (기준시점 대비 조사시점 가격비의 **기하평균** 방식)

즉 산술평균이 아니라 **기하가중평균(로그평균)**이고, 가중치는 **주택재고량**
(부동산가격정보체계, 매년 1월 1일 기준 재고 데이터)에 근거한다. 조사대상에서
공가·국공유·무허가·주거면적 50%미만 단독주택 등은 제외되므로(29p), 이 "재고량"은
순수 인구주택총조사 전체 재고가 아니라 **조사대상으로 인정되는 재고**를 의미한다.

다만 이 보고서 자체에는 **가중치의 구체적인 %수치는 실려있지 않았다**(24·25·29·32페이지
전부 확인했으나 "가중치 조정" 문구만 있고 실제 비율표는 없음).

## 2) 역산 — 실제 발표치로 가중치 추정

전세·월세 두 세트의 실제 수치가 **동일한 가중치**로 계산됐다고 가정하면(유형별 재고
비중은 전세/월세 상관없이 동일해야 하므로 타당한 가정), 미지수 3개(가중치 합=1 제약 포함)를
독립방정식 2개(전세용 1개 + 월세용 1개)로 정확히 풀 수 있다.

코드: [solve_rone_type_weights.py](./scripts/solve_rone_type_weights.py)

```
ln(1+종합%) = w_아파트·ln(1+아파트%) + w_연립다세대·ln(1+연립다세대%) + w_단독주택·ln(1+단독주택%)
```

### 결과

| 유형 | 추정 가중치 |
|---|---:|
| **아파트** | **62.69%** |
| **연립다세대** | **25.23%** |
| **단독주택** | **12.08%** |

**검산**: 이 가중치를 각각 전세·월세 데이터에 대입하면 두 경우 모두 정확히 **0.3800%**가
나와, 실제 발표치(0.38%/0.38%)와 소수점 4자리까지 완전히 일치한다 — 서로 다른 두 세트의
독립적인 수치가 동일한 가중치로 동시에 정확히 재현된다는 것은, 이 가중치가 우연이 아니라
실제 산정에 쓰인 값(또는 그와 거의 동일한 값)임을 강하게 시사한다.

## 3) 해석 — 왜 인구주택총조사 비중과 다르게 느껴질 수 있는가

일반적으로 인용되는 인구주택총조사 기준 전체 주택재고 구성비(아파트 ~63%, 단독주택 ~20%대,
연립+다세대 ~10%대)와 비교하면, 이번 추정치는 **연립다세대가 상당히 높고(25%) 단독주택은
낮다(12%)**. 이는 R-ONE 조사가 전체 주택재고가 아니라 **조사·공표 가능한 재고만** 포함하기
때문으로 보인다 — 특히 단독주택은 공가·무허가·주거면적50%미만 등 제외 조건이 많아(29p),
실제 조사대상 재고 비중이 인구총조사상 전체 재고 비중보다 상당히 낮아질 수 있다.
(정확한 재고량 원자료는 이 보고서에 없어 완전한 확인은 안 됨 — 필요하면 국토교통부
부동산가격정보체계 또는 통계청 주택총조사 원자료를 추가로 대조할 수 있음)
