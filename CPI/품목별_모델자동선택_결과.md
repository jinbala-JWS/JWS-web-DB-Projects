# 품목별 예측방식 자동선택 (2026-09-10, 182개 품목 전수 검증)

전기료·의류 6종에서 발견한 "동결처럼 보이지만 실은 패턴이 있다"는 문제를, **아직
특별 처리가 없는 나머지 품목 전체(가중치 1.0 이상, Tier B 제외 182개, 합계가중치
718.5)**로 확대해 체계적으로 검증했다. 하나씩 손으로 보지 않고, **4가지 예측방식을
24개월 워크포워드로 전부 계산해서 품목별로 가장 정확한 걸 자동 채택**하는 방식으로 바꿨다.

## 후보 방식 4가지

| 방식 | 설명 |
|---|---|
| 비계절ETS(현행) | Holt 감쇠추세 — 특별 처리 없는 기본값 |
| 계절ETS | 12개월 계절성 포함 |
| **계단평균(신규)** | 예측 대상월과 "같은 달"로의 과거 전월대비 변동만 모아 최근 5회를 가중평균(5,4,3,2,1 — 최신에 가중치 큼)한 값을 그 달의 기대 변동률로 쓰고, 나머지 달은 자연히 0%에 수렴 |
| **완전동결(신규)** | 그냥 직전 실측치를 그대로 이월(무조건 무변동 예측) — "패턴이 아예 없는 항목은 0.00%가 디폴트"라는 원칙을 코드화한 것 |

**채택 규칙**: 품목별로 4개 중 MAPE가 가장 낮은 걸 고르되, **비계절ETS(현행) 대비
15% 이상 상대개선이 없으면 굳이 바꾸지 않는다** — 작은 표본 노이즈로 방식이
흔들리는 걸 막는 최소개선폭 게이트.

코드: [select_item_model.py](./scripts/select_item_model.py) (검증 스크립트),
[forecast_september_2026.py](./scripts/forecast_september_2026.py)의 `load_item_model_selection()`/`step_weighted_forecast()` (실제 반영)

### 눈에 띄는 교차검증 — 이전에 지목했던 "미스 원인" 품목들이 여기서도 확인됨

- **호텔숙박료**(8월 실적검증에서 -9.62% 최대 미스 중 하나): 계단평균 채택, MAPE 5.28%→3.00%(-43%)
- **국내단체여행비**(8월 오락문화 카테고리 미스 원인): 계절ETS 채택, MAPE 5.60%→2.93%(-48%)
- **휴양시설이용료**: 계절ETS 채택, MAPE 5.42%→2.15%(-60%)
- **하수도료**(이전 점검에서 "비정기 고시"로 분류했던 품목): 계단평균으로 재시도하니 MAPE 0.64%→0.45%(-29%) 개선 — 완전 비정기는 아니고 약한 계절 경향이 있었던 것으로 정정

**8월 실적검증 때 "오차 큰 품목"으로 지목했던 것들이 이번 전수조사에서 실제로
고쳐졌다** — 문제를 발견하고(8월 검증) → 원인을 추정하고(전기료 사례로 패턴 파악) →
전체로 확대검증하고(이번 작업) → 실제 모델에 반영하는 흐름이 한 바퀴 돌았다.

## 총지수 영향

바텀업(458개 직접블렌드) 총지수가 120.278(9월 최초 예측) → 120.377로 이동했다.
공식 헤드라인(하이브리드)은 120.506 — 04·06·09는 여전히 탑다운을 쓰지만, 09의
바텀업 예측이 이번 수정으로 115.80(거의 실제 8월치와 동일)까지 좁혀져 탑다운·
바텀업 두 방식의 교차검증이 훨씬 촘촘해졌다.
