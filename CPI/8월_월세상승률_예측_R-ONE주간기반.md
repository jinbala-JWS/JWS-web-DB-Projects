# 8월 CPI 월세 상승률 예측 — R-ONE 주간 아파트 데이터 기반 (2026-08-25)

## 방법론

[전세 버전](./8월_전세상승률_예측_R-ONE주간기반.md)과 동일한 아이디어이지만 한 단계가
추가된다. **R-ONE 주간 통계는 매매·전세만 조사하고 월세는 없다**(주간 API 응답의
`BLD_GB` 값이 `01`(매매)·`02`(전세)뿐임을 직접 호출로 확인 — 월세 `03`이 아예 없음).
따라서 주간으로 관측 가능한 신호는 "아파트 전세"뿐이라, 이를 먼저 8월 아파트 전세로
합성한 뒤(전세 버전과 동일), **"아파트 월세 ~ 아파트 전세" 과거 12개월 관계로 회귀
변환**해서 8월 아파트 월세를 추정하는 단계를 추가한다. 이후 절차(연립다세대·단독주택
추정 → Jevons 합성 → CPI 회귀)는 전세와 동일하되, 회귀계수와 CPI 모델은 모두 월세용을 쓴다.

**절차**
1. (전세 버전 재사용) 8월 1~3주차 아파트 전세 주간 변동률 → 복리합성 → 8월 아파트 전세 추정(원값 0.3003% / 보정값 0.3339%)
2. 과거 12개월 "아파트 월세 ~ 아파트 전세" 관계를 회귀로 학습해 8월 아파트 월세로 변환
3. 연립다세대·단독주택 월세는 주간 통계가 없으므로, 과거 12개월간 "아파트 월세 대비 관계"를 회귀로 학습해 추정
4. 3개 유형을 Jevons 가중치(아파트62.69%/연립다세대25.23%/단독주택12.08%,
   [R-ONE_주택종합지수_가중치_분석.md](./R-ONE_주택종합지수_가중치_분석.md)에서 역산)로 합성 → "8월 R-ONE 주택종합 월세" 추정
5. CPI 월세 동시점 회귀모델(CPI = 0.2454×R-ONE + 0.0352, [R-ONE_CPI_전월세_회귀모델.md](./R-ONE_CPI_전월세_회귀모델.md))에 대입 → CPI 월세 8월 예측

## 1) 8월 아파트 전세 → 아파트 월세 변환

전세 버전에서 이미 구한 8월 아파트 전세(주간 3주 복리합성) 원값 **+0.30%** / 보정값
**+0.33%**를, 과거 12개월 "아파트 월세 ~ 아파트 전세" 관계로 변환한다.

| 년월 | 아파트 전세% | 아파트 월세% |
|---|---:|---:|
| 2025-08 | 0.06 | 0.13 |
| 2025-09 | 0.14 | 0.16 |
| 2025-10 | 0.24 | 0.24 |
| 2025-11 | 0.33 | 0.29 |
| 2025-12 | 0.38 | 0.34 |
| 2026-01 | 0.37 | 0.33 |
| 2026-02 | 0.30 | 0.30 |
| 2026-03 | 0.38 | 0.36 |
| 2026-04 | 0.41 | 0.42 |
| 2026-05 | 0.45 | 0.43 |
| 2026-06 | 0.49 | 0.47 |
| 2026-07 | 0.49 | 0.47 |

회귀: 아파트월세 = 0.8234 × 아파트전세 + 0.0511 (R²=0.9648, 매우 강한 선형관계 — 같은
아파트 내에서 전세·월세가 거의 같은 방향·크기로 움직인다는 뜻)

→ 8월 아파트 월세 추정: **원값 0.2984% / 보정값 0.3260%**

## 2) 연립다세대·단독주택 월세 — 아파트 월세 대비 과거 관계로 추정

과거 12개월(2025-08~2026-07) 데이터로 회귀:

| | 기울기 | 절편 | R² |
|---|---:|---:|---:|
| 연립다세대 월세 ~ 아파트 월세 | 0.617 | 0.001 | 0.922 |
| 단독주택 월세 ~ 아파트 월세 | 0.112 | 0.013 | 0.821 |

8월 아파트 월세 추정치(원값 0.2984%)를 대입: **연립다세대 +0.185%, 단독주택 +0.046%**

## 3) Jevons 가중합성 → 8월 R-ONE 주택종합 월세

**+0.239%** (원값 기준) / +0.261%(보정값 기준)

| 시나리오 | R-ONE 주택종합 월세 추정 | CPI 전월대비 예측 | **CPI 월세지수 예측** |

## 5) 다른 방법들과 비교

| 방법 | CPI 월세지수 8월 예측 |
|---|---:|
| 자체 히스토리 ETS ([2026년8월_CPI_예측.md](./2026년8월_CPI_예측.md)) | 105.95 |
| R-ONE 월간 1개월 시차모델 ([R-ONE_CPI_전월세_회귀모델.md](./R-ONE_CPI_전월세_회귀모델.md)) | 105.959 |

**세 가지 완전히 다른 방법이 105.92~105.96 범위(0.04포인트 이내)에 모여있다** — 전세
버전(106.26~106.33, 격차 0.05~0.08)보다도 더 촘촘하게 수렴했다. 월세는 회귀 R²가
전반적으로 전세보다 높아(아파트월세~아파트전세 0.9648, CPI동시점모델 0.5203 vs 전세
0.3611) 변환 단계가 하나 더 있음에도 오히려 오차가 덜 누적된 것으로 보인다. 8월 CPI
월세지수는 **105.92~105.96 구간**으로 좁혀볼 수 있다.

## 한계

- 이번 분석은 전세 신호를 월세로 옮기는 변환 단계가 추가되어 전세 버전보다 회귀 단계가
  하나 더 많다(전세: 2단계 회귀 → 월세: 3단계 회귀). 다만 각 단계 R²가 모두 0.8 이상으로
  높아 오차 누적이 크지 않았던 것으로 보인다.
- 연립다세대·단독주택의 "아파트 월세 대비 관계", "아파트 월세~아파트 전세 관계" 모두
  12개월치 회귀라 표본이 작다.
- 주간→월간 변환 자체가 근사치(전세 버전의 89.9% 검산 비율 참조)
- 8월 4주차(08.24 기준) 데이터는 아직 미발표라 3주치만 반영됨 — 8/27(목) 발표되는
  4주차를 반영하면 추정치가 더 정확해질 것
